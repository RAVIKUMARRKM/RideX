STEP 1: Add Google Maps API Key (1 minute)
------------------------------------------
File: C:\Users\Ravi Kumar\Apps\RideX\android\app\src\main\AndroidManifest.xml
Find: android:value="YOUR_GOOGLE_MAPS_API_KEY_HERE"/>
Replace with your actual Google Maps API key
Save the file

Get API key: https://console.cloud.google.com/


STEP 2: Open Android Studio & Configure Java (1 minute)
-------------------------------------------------------
1. Open Android Studio
2. File → Settings
3. Build, Execution, Deployment → Build Tools → Gradle
4. Gradle JDK: Select "17" (NOT 21!)
   - If not available, click "Download JDK" → Choose version 17
5. Click OK


STEP 3: Open Project (1 min + 10-15 min sync)
---------------------------------------------
1. File → Open
2. Select: C:\Users\Ravi Kumar\Apps\RideX\android
3. Click OK
4. WAIT for Gradle sync to complete (10-15 minutes first time)
   - It's downloading Gradle 8.5 and dependencies
   - Bottom bar shows progress
   - Success message: "Gradle sync finished successfully"


STEP 4: Build APK (3-5 minutes)
-------------------------------
1. Build → Build Bundle(s) / APK(s) → Build APK(s)
2. Wait for "BUILD SUCCESSFUL" message
3. Click "locate" to find your APK
4. DONE! 🎉
